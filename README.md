# Emotes Remapping Plugin

A RuneLite plugin for reordering and customizing emotes, with special support for Crack the Clue 3 (CTC3) emotes.

## Features

- **Emote Reordering**: Rearrange emotes to your preferred order
- **CTC3 Emotes Support**: Built-in support for Crack the Clue 3 emotes
- **Vault Location Detection**: Automatically enable/disable based on Varrock basement vault proximity
- **Custom Order Persistence**: Save your emote ordering preferences

## Installation

This plugin can be installed through the RuneLite Plugin Hub or by building from source.

### Building from Source

```bash
gradle build
gradle run
```

## Configuration

Access the plugin settings through the RuneLite configuration menu to:
- Enable/disable the plugin
- Configure location-based activation near Varrock basement vault
- Reorder your emotes by specifying a custom order
- Set default emote layouts

## Usage

1. Enable the plugin in your RuneLite settings
2. Optionally enable vault location detection
3. Configure your preferred emote order in the plugin settings
4. Your preferences are automatically saved
